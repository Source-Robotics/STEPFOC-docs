The header has four tabs. **STEPFOC Manual** is the document you read from the start: safety, technical data,
mounting, the first setup, operation and firmware updates, in numbered chapters. **Reference** lists every CAN
message and every UART command of the firmware release this site describes, with the defaults and the error flags,
and is where you look things up. **Guides** are worked examples with code. **Support** says where to get help and
how to report a problem.

The whole site describes one firmware release. The dropdown next to the site name switches between releases, and a
page from an older release says so in a bar at the top. The repository card on the right of the header opens the
firmware repository; every page ends with a link to edit it and one to report a problem with it.
