# About this guide

## Scope and audience

The Motor GUI Guide describes [motorgui.com](https://motorgui.com/): how to connect it to a driver or a bus, and
how to set up, calibrate, tune, monitor and update a driver from it. It assumes the driver is mounted and wired as
in the STEPFOC Manual. It describes the GUI as it is at the date of the revision; the GUI changes faster than the
firmware, so the version box names a revision, not a firmware release.
