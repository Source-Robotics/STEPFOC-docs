# With Motor GUI

[Motor GUI](https://motorgui.com/) is the driver's tool in the browser: it connects over the serial adapter or the
CANvas adapter, shows the state, moves the motor, runs the calibration, tunes the loops with live plots, records
telemetry and updates the firmware. Everything it does, the driver also does from a terminal or from Python; the
GUI reads and writes the same settings.

It has its own guide: the **Motor GUI** tab, starting with [Getting started](../motor-gui/01-getting-started.md).
The [Quick start](../quick-start.md) goes through the first setup in it.
