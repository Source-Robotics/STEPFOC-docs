# First setup

From a mounted and wired driver to a calibrated, tuned motor. Motor GUI in the browser is the usual tool for it;
every step also gives the terminal command, for a terminal or for the console in Motor GUI.

1. [Motor GUI](https://docs.source-robotics.com/STEPFOC-docs/108/05-setup/motor-gui/): the browser, the serial adapter, opening the port, what is on the screen.
2. [The serial terminal](https://docs.source-robotics.com/STEPFOC-docs/108/05-setup/terminal/): the alternative — PuTTY, the PlatformIO monitor or the Arduino monitor,
   and the `#` commands.
3. [Motor parameters and calibration](https://docs.source-robotics.com/STEPFOC-docs/108/05-setup/calibration/): the factory defaults, the motor's resistance, inductance and pole pairs,
   then the calibration run.
4. [Current limit and loop tuning](https://docs.source-robotics.com/STEPFOC-docs/108/05-setup/tuning/): the current limit for the motor, and the loop gains if the
   defaults do not suit it.
5. [Saving the configuration](https://docs.source-robotics.com/STEPFOC-docs/108/05-setup/saving/): nothing survives a power cycle until it is saved.

A driver that has been through these pages is ready for [Operation](https://docs.source-robotics.com/STEPFOC-docs/108/06-operation/). The
[Quick start](https://docs.source-robotics.com/STEPFOC-docs/108/quick-start/) is the same path on one page.
