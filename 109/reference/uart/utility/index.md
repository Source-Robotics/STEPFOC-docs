# Status and utility

| Command | Kind | Argument | What it does | Response |
|---|---|---|---|---|
| `#Vmax` | Set/Get | int: voltage in mV | The supply voltage above which a Vbus error is raised, 29000 mV after #Default. | `Vmax in mV: N` |
| `#Save` | Action |  | Writes the configuration to the EEPROM, and the CAN ID into the bootloader's board ID. Do it after calibration and after tuning. It also writes the serial number held in RAM (1 after a power-up, unless SERNUM set it) over the stored one. | `Save` |
| `#Reset` | Action |  | Resets the driver. From firmware 105 the reset lands in the bootloader, which waits 2 s for a flashing host and then starts the firmware again. | nothing |
| `#Tlim` | Set/Get | int: temperature in °C | The temperature at which the temperature error is raised; 75 by default. | `Temp limit N` |
| `#Default` | Action |  | Writes the factory defaults to the EEPROM and loads them: the serial number, hardware version and batch date; the gripper flag, heartbeat, watchdog and thermistor (off); the motor parameters and the calibration (cleared); every gain and limit; from firmware 109 also the tool id (0), the watchdog fallback, the calibration ID (0), the anti-cogging set, the encoder table and its trims (cleared), and parameter 56 (back to 2). From firmware 109 the CAN ID is kept (0 only when no valid one is stored). See Defaults. | `Loaded default config!` |
| `#Temp` | Get |  | Prints the thermistor temperature. | °C, or `Temp Off` while the thermistor is disabled |
| `#Term` | Set/Get | int: 0 or 1 | Enables the thermistor measurement and the temperature error (off by default). | the setting |
| `#Mode` | Get |  | Prints the control mode. The voltage-torque mode prints `Gripper mode`; HALL, the angle-offset search, open-loop steps (gosteps), gripper mode and the encoder-table run print nothing. | `Idle mode`, `Position control`, `Speed control`, `Current control`, `PD control`, `Open loop`, `Gripper mode`, `Gripper calib mode` |
| `#Vbus` | Get |  | Prints the supply voltage. | mV |
| `#Error` | Get |  | Prints which errors are active. | `No errors!` or `In error state!` followed by one line per active error |
| `#Clear` | Action |  | Clears the errors and goes to idle. An error whose cause is still present comes straight back; a calibration error is cleared only by calibrating (or `#Calibrated 1`). Enters **idle** mode. | `Clear errors` |
| `#Iabc` | Get |  | Prints the phase currents. | `Ia`, `Ib` in mA |
| `#PWM` | Get |  | Prints the PWM duty values. | the duties |
| `#Help` | Action |  | Prints a short command reference. Added in firmware 106. | the reference |
| `#Info` | Action |  | Prints the hardware version, batch date and firmware version, the control loop's execution time, the CAN ID, the calibration state, the thermistor and the supply voltage, the phase direction, phase order and commutation direction, and the motor parameters (pole pairs, angle offset, R, L, Kt, KV). From firmware 109 also the build, the board ID and the calibration ID, the CAN receive overruns and dropped transmits, the product, the current-sense zeros, the tool id, the watchdog and its fallback, settings block 2, the anti-cogging, and at the end the `In force:` section (see Status and diagnostics). Not the serial number (SERNUM), the gains (Param) or the errors (Error). | the report |
| `#Tool` | Set/Get | int: 0 to 255 | The tool id: what the drive is built into, 0 none, 1 SSG-48, 11-33 MSG (tens = rail 1/2/3 = 100/150/200 mm, units = stepper 1/2/3 = 21.5/40/60 mm), 200-254 your own. The same as parameter 1. Kept by Save. Added in firmware 109. | `Tool ID: N`, or `Invalid tool id (0-255)` |
| `#Tone` | Set/Get | f,mA[,ms], or off | A tone through the motor (see Sound): `#Tone 440,250,1000` plays 440 Hz at a loudness of 250 mA for 1000 ms, on the axis parameter 82 picks. mA left out: 200; ms left out: 500; ms 0: until `#Tone off`. 20 Hz up to below 3125 Hz. It plays only while the driver holds or moves; from idle a calibrated driver first holds the position it is at (`#Idle` releases it). `#Tone` alone or `#Tone off` stops all sound. Added in firmware 109. Enters **position** mode. | `Tone 440 Hz, 250 mA, 1000 ms`; from idle first `Holding the position while it plays (#Idle releases it)`; `Tone: not played (…)` when it cannot; `Tone off` |
| `#Par` | Set/Get | int: n, or n,value | Any parameter by its number (see Parameters and buffers): alone it lists every parameter, `#Par 56` reads one, `#Par 56,0` sets it (no spaces); a gain or limit (8-16, 20) takes a decimal, e.g. `#Par 9,0.02` sets Kpv. Added in firmware 109. | `P<n> = <value>`; `refused: out of range, read only, not now, or unknown` when the driver did not take it; `P<n> unknown` |
| `#Product` | Action | nothing, or claim, clear | The product lock: prints this firmware and the board's stamp. `claim` stamps the board as this product (a repaired board, a motor the stamp rule misjudges), `clear` removes the stamp; power-cycle after either. Over UART only. Added in firmware 109. | `Firmware: STEPFOC; board stamp: …` |
| `#WdFb` | Set/Get | int list: time_ms,current_mA,speed_ticks_s,after_action | The watchdog fallback, four numbers at once without spaces, e.g. `#WdFb 2000,0,1000,2`: how long hold or descend runs, descend's current and speed cap, and what follows (0 legacy, 2 brake, 3 coast). The same as parameters 2 to 5, clamped the same way; fewer than four numbers change nothing. Kept by Save. Added in firmware 109. | `Watchdog fallback: … ms, … mA, … ticks/s, then …` |
| `#Param` | Get |  | Prints every gain of every loop. | the gains |
| `#Cyc` | Set/Get | int: interval in ms (0 = off) | Sends position, speed and Iq on its own every interval: `$ <position> <speed> <Iq>`; for BetterSerialPlotter. | `Cyclic disabled` when turned off |
| `#Cyca` | Set/Get | int: interval in ms (0 = off) | Like Cyc, in the Arduino plotter format `Position:x,Speed:y,Iq:z`. | `Cyclic disabled` when turned off |
| `#CANID` | Set/Get | int: 0 to 13 | The CAN node ID. Use 0 to 13: the firmware accepts 14 and 15, but the bootloader reserves them and a driver on one of those cannot be updated over CAN. Kept over a power cycle after Save, which also writes it into the bootloader's board ID; from firmware 109 Default and a settings reset keep it too. | the ID, or `Invalid CAN ID` |
| `#SERNUM` | Set/Get | int: number | The serial number. This firmware does not read it back from the EEPROM at power-up: it reports 1 until set, and Save writes the value in RAM over the stored one. | `Serial number is: N` |
| `#Activate` | Action |  | Sets the activated flag. | `Controller activated` |
| `#Pullconfig` | Get |  | Prints the whole configuration on one line, for Motor GUI. | the configuration |
| `#LED` | Set/Get | int: 0 or 1 | Turns the status LED on or off. | the LED state |
